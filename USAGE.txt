Affine 一键整合部署器

只需要 AffineDeployer.exe 一个文件，整合模板已内置，不需要把旁边的 DLL 或脚本一起带走。
Windows 使用系统 .NET Framework 4.7.2 或更高版本。

1. 退出游戏和 AMDaemon。
2. 双击 AffineDeployer.exe，选择未经整合的原版 affine_io.dll。
3. 选择游戏根目录，即包含 Sinmai.exe、start.bat、segatools.ini 的目录。
4. 点击“一键整合并部署”，完成后用游戏原来的 start.bat 启动。

自动执行
- 生成并部署 affine_io_single.dll，包含原生 I/O、灯光转发和实体 Coin 加点。
- 将 segatools.ini 的 [mai2io] path 改为 affine_io_single.dll；[io4] enable=1、[button] enable=0。
- 在 start.bat 中保留原启动参数，确保 AMDaemon 和 Sinmai 都由 mai2hook 注入，增加启动等待。
- 配置 AquaMai VirtualCoin：CoinKey=None、IsUseRemote=false、IsPlaySound=false。
- 备份旧文件，并禁用 Mods 内 AffineHostProbe.dll / AffineGameLights.dll。

原版 affine_io.dll 和 mai2hook.dll 不会修改。游戏需已有 mai2hook、inject、MelonLoader net35 和 AquaMai。
备份位于游戏目录 AffineDeployBackups，每次部署单独保留。选择同一游戏目录后点“恢复上次部署”，可以回到上次部署前的文件状态。
“仅生成单 DLL”可以生成文件，不修改游戏配置。
重复部署可用于以后更新兼容的原版 affine_io.dll，不要选择已经整合过的 DLL。

投币点数重启后清零。本机已验证实体加点和扣点；当前测试板没接灯，实体灯光尚未验证。
工具针对当前 SDGB1.56 / MelonLoader 0.6.4 net35 / AquaMai 1.9.18 环境，不保证任意新版协议或复杂启动脚本兼容。
目录权限不足时以管理员身份运行。
